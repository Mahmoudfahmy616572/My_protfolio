· Google Maps & MapTiler · Paymob · REST (dio/http) · GitHub Actions + GitHub Pages

## Run locally

```bash
git clone https://github.com/Mahmoudfahmy616572/My_protfolio.git
cd My_protfolio
flutter pub get
flutter run -d chrome          # web
```

Project copy lives in `lib/localization.dart` (EN/AR) and is rendered by
`lib/screens/home_page.dart`.
